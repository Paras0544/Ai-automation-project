# House rules (learned)

The planner reads this file before every look. Claude's weekly review adds and
edits rules here based on your feedback and how reels perform. You can edit it too.
Keep each rule one line, starting with "- ".

## Style
- Prefer clean, classic combinations (navy, beige, white, olive, brown) over loud prints.

## Hooks & captions
- Hooks name a real situation the viewer is in (a date, a wedding, office), not a generic style tip.

## Products
- Never put sneakers with ethnic wear; use juttis/mojaris or loafers.
